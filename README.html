02 · Core methods

What the models actually do.

The two spatial questions are deliberately separated: first identify contiguous built-up fabric; then ask how much of that urban population can reach useful public transport.

Grow the morphological city

Population density, building coverage, and local-street density become a balanced score. Adjacency grows only through shared edges; water is a hard exclusion.

urban scorewater mask

Measure the reachable population

Stations generate network-distance catchments. Catchments are dissolved before coverage, then each cell contributes population by building footprint—or by intersected area where footprints are absent.

Why not centroids? A cell can be partly covered. The published 2025 Oslo figure (60.65%) used centroid containment; each new run records both centroid and weighted results so the methodological delta is explicit.

Route a weekday morning

GTFS supplies schedules; r5py combines them with a clipped OSM PBF. Every population-cell centroid departs during a two-hour window and routes by walk + transit.

Publish comparable evidence

Working CRSs stay local and metric. Publication reprojects every city to equal-area EPSG:3035 and writes a temporary GeoPackage before one atomic replacement.

03 · Study areas

Six cities, one contract.

Each city keeps the projected CRS suited to its local calculations. Publication—not analysis—is standardised to EPSG:3035. Feed tolerances remain city-specific because station names and operator structures differ.

04 · Run it

Generate the command.

The runner skips only when both the city-config hash and code-version fingerprint match a completed state file. Use force when source data or external feeds need an intentional refresh.

python run_study.py --cities all --stage all
